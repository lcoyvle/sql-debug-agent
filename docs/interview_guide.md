# SQL Debug Agent 面试讲解指南

## 60 秒项目介绍

我做了一个面向金融分析场景的 SQL Debug Agent。它不是直接做 Text-to-SQL，而是接收
用户问题、数据库 Schema、错误 SQL 和执行反馈，调用模型修正 SQL，再通过 SQLite
工具验证结果。项目从 Qwen2.5-Coder-1.5B 的 Base 评测开始，根据 JOIN、日期和重复
计数等 Bad Case 自建 218 条 SFT 数据，而不是直接下载数据集。SFT 把冻结测试集正确率
从 57.1% 提升到 82.1%。之后我从真实 rollout 中提取 26 条失败难例，用两套不同数据
的数据库设计防奖励作弊的执行奖励，再做 40 步 GRPO，最终达到 89.3%，相对 SFT 修复
2 题且没有回退。

## 项目链路

```text
Base 评测
  → 按 Bad Case 倒推数据
  → QLoRA SFT
  → 冻结集验证与回退分析
  → 真实 rollout 构建 hard prompts
  → 双数据库奖励
  → GRPO
  → Base / SFT / GRPO 最终对比
```

## 面试官最可能追问的问题

### 为什么不是一开始就做 RL？

初始模型连基本 JOIN、字段和日期修复都不稳定，这属于监督信号能直接教授的能力。
如果此时做 RL，奖励只能放大一个不稳定策略。先做 SFT 建立格式和基础能力，再检查
SFT 剩余问题是否适合用可验证奖励优化。

### 你是怎么构建数据的？

先从金融分析问题写出正确 SQL，再按七类错误模板注入一个可解释的错误。每条数据都
经过 SQLite 自动验证：参考 SQL 必须可执行，错误 SQL 必须与参考结果不同。切分时按
`template_id` 分组，避免同模板改写泄漏到训练集和验证集。

### 为什么需要两套数据库？

错误 SQL 可能在小数据上碰巧和正确 SQL 返回相同结果。例如漏掉筛选条件，但当前表里
恰好所有行都满足条件。只有候选在两套相同 Schema、不同数据分布的数据库上都匹配
参考结果，才给答案奖励，从而降低 reward hacking。

### 为什么使用 GRPO？

任务能为同一问题采样多个 SQL，并通过数据库执行得到客观奖励，不依赖昂贵人工标注。
GRPO 可以直接比较同组候选的相对奖励，适合这种可验证任务。普通 corrective SFT
负实验没有改善，是因为它只学习 chosen SQL，没有使用 rejected SQL 的相对信息。

### 第一次 GRPO 为什么没有效果？

第一版每题只生成两个候选，而且 SFT 后模型输出非常确定，所有候选奖励相同，
`reward_std=0`，所以 advantage 和梯度基本为零。我没有把“训练命令跑完”当成有效
实验，而是改用 26 条真实失败难例、把候选数增至 4，并提高采样温度。

### 只有 3/40 步有奖励方差，是否说明 GRPO 不可靠？

它说明学习信号确实偏稀疏，所以报告中明确列为局限，不能只看训练 loss。但冻结测试
集上 GRPO 相比 SFT 提升 2/28 且无回退，说明这次小实验存在可测量收益。更严谨的后续
工作应扩大 hard prompt 数量，并使用新的冻结测试集复验。

### 你如何避免过拟合和数据泄漏？

- 最终 28 题在对应训练前冻结；
- 最终测试集不放进 SFT/GRPO 训练压缩包；
- 数据按模板分组切分；
- checkpoint 只用开发集选择；
- 最终评测关闭随机采样；
- 查看最终测试答案后不再继续用它调参。

### 为什么不用 SQL 字符串完全一致作为指标？

同一查询可以有不同但等价的 SQL 写法。项目比较有序执行结果，而不是要求模型复制
参考 SQL 的字面形式；同时仍检查只读安全性，并使用双数据库减少偶然等价。

## 可直接放进简历的一句话

构建执行反馈驱动的金融 SQL Debug Agent，自建并验证 218 条 SFT 数据与 26 条真实
rollout GRPO 难例，设计双 SQLite 防作弊奖励；使用 QLoRA SFT + TRL GRPO 将 28 题
冻结集 execution-match 从 57.1% 提升至 89.3%，GRPO 相对 SFT 提升 7.1 个百分点且
无任务回退。

4. 展示双数据库奖励代码和危险 SQL 单元测试。
5. 展示最终报告中 SFT→GRPO 修复 2 题、回退 0 题。

## 主动说明的局限

- 28 条冻结测试集较小。
- 只有一个金融 Schema。
- GRPO 有效奖励差异只有 3/40 步。
- 尚未评估 SQL 查询成本和真实用户满意度。

主动说明这些限制通常比夸大效果更有说服力，因为它表明你理解实验结论的适用边界。
